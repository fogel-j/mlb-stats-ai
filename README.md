# MLB Stats GPT


This package serves ChatGPT with up-to-date baseball news and statistics from popular data stores like Baseball Reference, Baseball Savant, and FanGraphs. 

## What are GPTs?

Comprehensive APIs for OpenAI's LLM to access real-time information.

[https://openai.com/index/introducing-gpts/](https://openai.com/index/introducing-gpts/)


## Usage

Just ask ChatGPT and explore the possibilities. I've made a lot of API operations for exploring all types of statistics.

## Known Issues

OpenAI has nerfed GPTs so it's likely to give errors that I can't fix. You might get errors that the "ChatGPT can't connect to the API". My API is available 100% and is recognized in builder mode.
